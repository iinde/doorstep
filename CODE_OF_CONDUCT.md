# Code of Conduct

Doorstep is for everyone. In issues, discussions, pull requests and anywhere else we meet:

- **Be kind.** Assume good intent. Many people here aren't developers, and every question is welcome.
- **Be respectful.** No harassment, insults, or personal attacks. No discrimination of any kind.
- **Respect privacy.** Don't post other people's personal information, or footage, addresses or number plates of anyone's home, including your own neighbours.
- **Stay on topic.** Help each other make Doorstep better.

If someone isn't following this, please report it to the maintainers using GitHub's **Report content** option or by opening a private [security advisory](https://github.com/iinde/doorstep/security/advisories/new). Maintainers may remove comments, lock threads or block people who don't follow it.

This code is adapted from the [Contributor Covenant](https://www.contributor-covenant.org), version 2.1.
