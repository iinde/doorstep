# Doorstep 0.5.2

## Safer
- **Locked down against tampering.** Doorstep now runs with Apple's hardened runtime, so other software on your Mac can't slip code into it and get at your Ring sign-in.
- **Updates only come from Doorstep's own feed.** Release builds ignore any attempt to point updates somewhere else. Every update was already checked against Doorstep's signature; this closes the door one step earlier.
- **A nudge on weak ntfy topics.** Anyone who guesses an ntfy topic can see the alerts sent to it, so Settings now warns you if yours is short and suggests a long random one.
