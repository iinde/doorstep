# Doorstep 0.7.2

## Safer
- **Up-to-date video engine.** The part of Doorstep that receives live video (WebRTC) moves from a mid-2024 build to the October 2026 one, bringing in more than two years of security fixes.

## Better
- The Doorstep window no longer redraws itself every second, so it uses less power while open.
- "Say it at the door" can no longer get stuck on "Connecting" if the call to the camera never comes up. It tells you it couldn't speak and lets you try again.
